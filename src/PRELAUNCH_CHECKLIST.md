# 慢半拍譜間｜四件套整合與正式上線前驗收表

## A. 本地啟動

- [ ] `npm.cmd run build` 完成，沒有 Vite／TypeScript 錯誤。
- [ ] `npx.cmd wrangler pages dev dist --port 8788` 能成功啟動。
- [ ] 管理員可登入、登出；朋友登入可瀏覽／播放但不能管理。

## B. 四件套規則（所有類型共用）

- [ ] 新增鋼琴譜、吉他彈唱譜、吉他指彈譜時，MusicXML、PDF、MP3、MIDI 缺一不可。
- [ ] 任意少選一份，儲存被阻止並列出缺少項目。
- [ ] 無效的 MusicXML 內容會被拒絕，而不是只看檔名或 URL 是否非空。
- [ ] 單曲匯入後重新整理，四份附件仍存在、能從曲庫讀取。
- [ ] 批次匯入能把同主檔名的 `.musicxml/.xml`、`.pdf`、`.mp3`、`.mid/.midi` 配成一組。
- [ ] 缺少／重複其中一類的批次檔案會被略過，不會建立不完整曲目。
- [ ] 舊資料缺附件時顯示「素材未齊」，補齊前無法進入主閱讀器。
- [ ] 朋友帳號不能 PUT／DELETE 附件 API；未登入不能讀附件索引或附件本體。

## C. 統一曲庫

- [ ] 一個首頁能篩選全部／鋼琴譜／吉他彈唱譜／吉他指彈譜。
- [ ] 搜尋、收藏、編輯、刪除與重新整理後的列表正常。
- [ ] MusicXML 能自動填入曲名、藝術家、調性、拍號、速度、小節數。
- [ ] 每筆曲目均顯示四份附件狀態；缺檔標記清楚。

## D. 鋼琴譜

- [ ] 從曲庫開啟完整四件套的鋼琴譜，確認 PDF 顯示譜面、MP3 是實際音源、MIDI 可參與時間對位、XML 有小節結構。
- [ ] 縱向 PDF 頁面、縮放、單頁／雙頁、播放／暫停、進度拖動、小節跳轉、游標跟隨正常。
- [ ] 測試速度、前後跳秒、A/B 循環、第一小節／每行首小節／行尾與跨行游標。
- [ ] 和弦／級數標籤能對應且不遮擋譜面。

## E. 吉他彈唱譜（本次新閱讀路由需特別回歸）

- [ ] 從主曲庫開啟四件套完整的彈唱譜，預設顯示 PDF，音源來自 MP3，MIDI 參與時間對位。
- [ ] 播放、暫停、拖動進度、點小節跳轉與游標跟隨正常。
- [ ] 對比舊版閱讀器：把曲目 URL 改成 `?scoreRoomId=曲目ID&legacyVocalReader=1`，確認原本 `ScoreReader.tsx` 還能正常開啟；其原始碼沒有被替換。
- [ ] 若新 PDF 閱讀器無法保留原有彈唱互動，記下差異並先停在本地，不要部署。不得為修新路由直接覆蓋舊 `ScoreReader.tsx`。

## F. 吉他指彈譜

- [ ] PDF 五線譜＋六線 TAB 的小節高亮範圍上下左右準確。
- [ ] MP3 播放／進度／點小節跳轉正常；游標不是單純每小節固定匀速。
- [ ] 回測第 8、9 小節內部音符，並檢查跨行、跨頁及末行。

- [ ] 匯出 JSON 備份；知道它不包含 PDF／MP3／MIDI 二進位，另有四種原始檔與雲端附件備份。
